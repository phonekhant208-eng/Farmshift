# FarmShift (merged: base app + Module 4)

## Run
    npm install
    npm run dev          # open http://localhost:3000

Needs Node 20+ and internet (NASA POWER + map tiles).

## Other
- `npm run build && npm start`  production run
- `npm run verify`              Module 4 test cases (Node 22+)
- /api/environment?lat=..&lon=.. live data
- /api/scenario?id=A|B|C        test-guide CSVs in data/scenarios
- /inspector                    raw data inspector
